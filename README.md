# Automação de Tarefas com Python

Este projeto tem como objetivo te mostrar como você pode **automatizar tarefas repetitivas** utilizando **Python**.  
São tarefas do dia a dia, que você pode fazer em casa ou no seu trabalho — e que normalmente tomariam muito tempo se feitas manualmente.

## 🚀 Por que automatizar?

Imagine ter que cadastrar quase 300 produtos, cada um com 6 ou 7 informações diferentes...  
Além de ser demorado, há uma grande chance de cometer erros — colar um dado no campo errado, digitar algo incorretamente, etc.

Com **automação**, o processo se torna:
- Mais rápido 🕒  
- Mais confiável ✅  
- Mais eficiente ⚡

## 📦 Tecnologias usadas

- Python 3
- PyAutoGUI
- Tempo e criatividade 😄
